## 完整可得动作账本与双层证据

> 本机可得的是**全部本轮持久化的动作/决策条目**及一次运行中的 `/strategy`，不是“全部原始模型对话 HTTP 请求与响应”。`/decisions` 最多给最近 50 条；完整动作账本在 gitignored 的 `build/live-2026-09-23/decisions.jsonl`（79 条），运行范围还保存在 `build/live-2026-09-23/sessions/*.json`（76 条）。原始提示词、SSE 增量、Jev 备选方案和完整供应商响应**没有在当前系统中持久化**；不能凭这些动作记录伪造请求与结果的完整逐包审计。

- 79 条总计：手动 HTTP 引导 **3** 条、模型常规 `agent_loop` **54** 条、Jev 执行 **22** 条。运行内 76 条，与会话记录吻合。会话还存有 **84 条 chat**：76 条动作展示、8 条已完成的 assistant 发言；没有每轮的 `user/system/tool` 原始消息和完整 SSE，因此并非 84 次完整的供应商请求。八条发言分别涉及两次零能量只能结束回合、地图路线评估、出牌后无能量、地图唯一选项、墨宝战斗集火/剥离滑溜与查看卡牌奖励；全文只保存在本地隔离会话，报告不复制。Jev 从第 46 条之后才出现；开启双层之前的 LLM 动作不能倒算为 Jev。
- Jev 的 22 条里 `end_turn` 8、`play_card` 5、`choose_map_node` 3、`collect_rewards_and_proceed` 3，另外选卡、休息、继续各 1。每条已接受 Jev 动作均有请求计数 1 和置信度；这比只看设置 `dualLayerSoloEnabled=true` 更能证明 **Jev 确实承担了部分实际操作**。
- 运行中 `/strategy` 曾返回 `dual_layer=true`、`jev_configured=true`、`strategy.source=llm`、策略更新时间与 `option_hints`。退出后的会话 `strategy.source=llm`，更新时间约 23:56:25。**当时部署的旧版** `JevExecutionDecider.BuildRequest` 把策略 `posture/instructions/option_hints`、屏幕 playbook 和实时 compact state 一并传给 Jev；`StrategyPlanner.RefreshAsync` 生成宏观策略，不直接操作游戏。因此**规划→执行管线有实际证据**，但旧版直接透传以动作类型 `play_card` 为键的提示，而同一 Jev 请求的选项以具体 ID（如 `play_card:0->1`）为键；提示不匹配具体备选动作是本轮代码审计确认的接口缺陷。新版已离线修复映射和添加宏观目标，但旧局无法倒推“Jev 已按目标行动”，逐步质量仍待复验。
- 接受动作条目（不等同于总计费）内，`agent_loop` 54 条合计至少 **105 请求 / 901,646 tokens**，Jev 22 条合计 **22 请求 / 88,451 tokens**。LLM 规划请求在回合账本外预留费用，失败请求/无动作回退也可能未产生已接受动作，因此以上不能当作所有供应商实际计费总额。该成本说明当前双层尚不能直接宣称“成本/速度最优”；需要同等局面、同等配置和完整请求账本对照。

### Jev 连续 `end_turn` 的确切界限

- 条目 61–65（约 23:53:46 至 23:54:41）连续为 Jev `end_turn`，置信度约 **0.36–0.52**；五个动作的 `state_fingerprint` 均不同，之后又有 LLM 与 Jev 的 `play_card`，并继续到奖励屏。因此是**不同游戏状态下真实推进的回合**，不是同一动作被原样重放或画面完全不动的死循环。
- 低置信度仍值得调查，但旧账本**没有记录每一步的能量、手牌可用性、Jev 枚举后的备选动作列表、Jev 完整响应，也未保存历史策略版本**。无法由此确定是否“明明可出牌却提前结束回合”。上一条动作后的状态和后来截图也不能代替这五个具体决策时刻。既不能宣称这五次战术正确，也不能仅按连续 `end_turn` 判成模型不理解游戏。
- 后续再验收双层质量时，需要以本地受控、**默认不含密钥/完整原始提示词的脱敏逐回合证据**捕捉：屏幕/回合/能量、可打卡与目标、提供 Jev 的 option IDs、策略修订号、Jev 选择/置信度、实际动作结果，以及是否回退 LLM；每条 trace 对齐同一个决策 ID。普通游戏日志不足以重构此证据，不能在未取证时称“最优化”。
