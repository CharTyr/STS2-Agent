[h1]STS2 AI Agent[/h1]
Connect an AI to Slay the Spire 2: configure an LLM in-game to play or co-op beside you, or hand control to external agents like Claude Code, Cursor, or Codex over MCP.

[b]No free credits or hosted API included.[/b] In-game auto-play uses your own OpenAI-compatible API key (DeepSeek, OpenAI, SiliconFlow, etc.) or local Ollama / LM Studio, with adjustable request and token caps. External-agent takeover needs no in-game API key. No new cards or balance changes.

[h2]Four ways to play[/h2]
[list]
[*][b]Auto-play & Spectate[/b]: handles routing, combat, shops, and events. Includes 3 one-click presets, whole-turn planning, and pre-play highlight dwell — press [b]F7[/b] anytime to intercept and take over, or switch on non-combat-only mode to fight manually.
[*][b]Local AI Teammate[/b]: from the main menu, open Play → Multiplayer to launch a second game window. Each player runs their own character in the same run, with co-op save resume, live teammate HP/hand status, chat, and quick focus-fire commands. All 4 lobby seats stay open for friends.
[*][b]External Agents (MCP / HTTP API)[/b]: built-in local Streamable HTTP MCP server and REST/SSE API on [b]127.0.0.1[/b] — no Python required. For solo play, enable Settings → MCP and copy ready-to-paste config for Claude Code, Cursor, or Codex. For co-op, switch Play → Multiplayer to External Agent mode to spawn a teammate window with its own local MCP address for an outside agent to drive. Pairs best with the [url=https://github.com/CharTyr/STS2-Agent/tree/main/skills/sts2-mcp-player]sts2-mcp-player[/url] skill; an optional Python MCP sidecar (stdio / layered / full profiles) is available on GitHub.
[*][b]In-run Advisor[/b]: ask "which card?" or "which path?" against live state, or save short cross-run playstyle notes to steer decisions.
[/list]

[h2]Quick start[/h2]
[olist]
[*]Subscribe and launch from Steam using [b]Play with Mods[/b].
[*]Accept the mod prompt on first launch, enable [b]STS2 AI Agent[/b] in the Mods menu, and restart (remove any older manual copy from the game's mods folder first).
[*]Press [b]F8[/b] (or click the [b]AI[/b] edge tab):
  — [b]In-game model[/b]: enter your provider, API key, and model under Settings → Quick setup, run [b]Test main model[/b], then start from the Play tab (invite a teammate from the main menu).
  — [b]External agent[/b]: for solo, toggle Settings → MCP and copy the client config; for co-op, return to the main menu, switch Play → Multiplayer to External Agent, launch the teammate, and copy its MCP URL.
[/olist]
