STS2 AI Agent 是《杀戮尖塔 2》的游戏内浮层。你照常操作自己的角色；同一台电脑上可以再开一个窗口，让 AI 打第二个角色。模型由你自己提供（OpenAI 兼容接口）。本物品不包含 API Key、帐号或托管模型。

更完整的安装说明、MCP / HTTP API 与开发者文档：
[url=https://github.com/CharTyr/STS2-Agent]https://github.com/CharTyr/STS2-Agent[/url]

[h2]快速上手[/h2]
[olist]
[*]在此订阅。Steam 库中点击开始游戏，选择 [b]带 Mod 启动 / Play with Mods[/b]。直接运行 exe 可能会跳过 Mod 加载器。
[*]接受不受信任代码提示，完全重启游戏，在 Mods 里启用 [b]STS2 AI Agent[/b]，再重启一次。
[*]按 [b]F8[/b]，或点屏幕右侧 [b]AI[/b] 标签。
[*]打开设置，添加 OpenAI 兼容提供商：HTTP/HTTPS 地址、模型名、可选 API Key。本地 Ollama / LM Studio 可以留空 Key。
[*]用「对话」或「游玩」操作你自己的角色。
[*]回到 [b]主菜单[/b]，打开 [b]AI 队友[/b] 并邀请。会再开一个窗口（本地 1 人 + 1 AI），加入同一间 4 人大厅，仍留 2 个在线席位。AI 只操作它自己的角色。
[/olist]

如果你以前把本 Mod 手工复制进游戏 [b]mods[/b] 目录，请先删掉那些文件，避免出现两份。

[h2]创意工坊包含什么[/h2]
[list]
[*]游戏内浮层：设置、对话、自动/单步游玩、邀请 AI 队友、可选截图
[*]同机双开：Steam 主机 + 独立离线帐号的第二窗口
[*]不新增卡牌、遗物、平衡改动，也不改存档格式
[/list]

[h2]不包含什么[/h2]
可选的 Python MCP 服务和开发者脚本只在 GitHub 提供。玩家开玩不需要它们。

[h2]兼容性[/h2]
需要杀戮尖塔 2 [b]v0.111.0[/b] 或更新版本。许可证：AGPL-3.0-only。
