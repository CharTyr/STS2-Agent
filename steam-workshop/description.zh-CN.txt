[h1]STS2 AI Agent[/h1]
爬塔爬累了？叫个 AI 来陪你。

它可以接过你的角色替你打，你也可以在旁边看着它打；或者干脆再开一个游戏窗口，让它扮演另一个角色，你们俩组队一起往上爬——同一局，各打各的牌。

模型用你自己的就行：DeepSeek、硅基流动、ChatGPT，或者电脑上跑的 Ollama / LM Studio 都可以。订阅这个 Mod [b]不会[/b]送你任何账号或 API Key，烧的是你自己额度的 Token——不过别慌，窗口里随时能看到这一局花了多少，花超了它会自己停下来。

[b]这个 Mod 还在开发中。[/b]难免有没做完或者出毛病的地方。碰到问题、有什么想法，欢迎来 [url=https://github.com/CharTyr/STS2-Agent/issues]GitHub Issues[/url] 说一声，真的有用。

想看更详细的说明、装不上怎么办、或者你是开发者想接自己的工具：
[url=https://github.com/CharTyr/STS2-Agent]https://github.com/CharTyr/STS2-Agent[/url]

[h2]你想怎么玩？[/h2]
[list]
[*][b]让它替你打[/b]：AI 接管你的角色，选路、出牌、进商店全包。你可以全程当观众，也可以让它一步一步来，不满意随时喊停自己上。
[*][b]让它当队友[/b]：主菜单里点「AI 队友」邀请一下，会弹出第二个游戏窗口。它只打自己的角色——自己点事件、跟着你投票选路、轮到自己就出牌。房间还是 4 人位，剩下的位置照样能拉朋友进来。打到一半存了档，下次读档它会自己连回来。
[*][b]就聊聊天[/b]：「这张牌要不要拿？」「前面走左边还是右边？」它看着当前局面给你出主意。路上它也会主动搭话，话多话少、什么语气，设置里都能调。
[/list]

[h2]怎么开始[/h2]
订阅就行，不用拷任何文件。
[olist]
[*]点订阅，等 Steam 下载完。
[*]在 Steam 里点开始游戏，选 [b]带 Mod 启动 / Play with Mods[/b]。直接双击 exe 是看不到 Mod 的。
[*]第一次启动会提示代码不受信任，点接受，然后把游戏彻底关掉重开。
[*]进 Mods 菜单，打开 [b]STS2 AI Agent[/b]，再重启一次。
[*]进游戏按 [b]F8[/b]，或者点屏幕右边那条 [b]AI[/b] 小标签。
[*]打开「设置」：添加端点 → 添加模型并绑定 → 选好对话/游玩各用哪个 → 点「测试连接」（会真的发一个请求过去）→ 保存。用本地 Ollama / LM Studio 的话 Key 留空就行。注意：只填了默认值不算配好，测试通过了才算。
[*]想让它替你打：切到「游玩」页点开始。想要队友：等游玩模型测试通过，回到[b]主菜单[/b]，在「AI 队友」页点邀请。
[/olist]

如果你以前手动把这个 Mod 拷进过游戏文件夹，记得删掉那些文件，只留工坊订阅，不然游戏里会出现两份。

[h2]装了它能干嘛[/h2]
[list]
[*]所有事都在游戏内一个窗口里办：AI 队友、对话、游玩、设置、接入、决策日志，六个页签，按 F8 随时叫出来
[*]它每打一步都交代得明明白白：出了什么牌、为什么出、这步花了多少 Token，决策日志里一条条都记着；这一局的花费和整个会话的花费分开算
[*]队友那个角色的血量、格挡、能量、手牌数，主窗口里实时看得到
[*]花多少钱你说了算：设好 Token 和请求数上限，撞到就停，不会偷偷超支
[*]8 套界面主题随便换（包括浅色），窗口拖到哪、选了什么主题，下次打开都记得
[*]界面跟着游戏语言走：中文客户端显示中文，其他语言显示英文
[*]想用自己的 AI 工具（Cursor / Claude / Codex）来玩也行：F8 →「接入」打开 MCP，复制地址给它就好，不用装 Python。想让它打得跟游戏内自动游玩一样稳，记得把配套 skill [url=https://github.com/CharTyr/STS2-Agent/tree/main/skills/sts2-mcp-player]sts2-mcp-player[/url] 也装上
[*]不加新牌、不改数值、不动你的存档
[/list]

需要《杀戮尖塔 2》[b]v0.111.0[/b] 或更新版本。许可证：AGPL-3.0-only。
