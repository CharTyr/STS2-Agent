STS2 AI Agent 为杀戮尖塔 2 提供游戏内 AI 助手浮层。你可以配置自己的 OpenAI 兼容接口，与 Agent 对话、让它分析当前局面，或通过游戏内窗口自动执行合法操作。

功能
- 游戏内对话、模型配置、按模型设置思考强度，以及可选的截图上下文
- 自动或单步处理战斗、奖励、地图、事件、商店、休息点、宝箱等已支持界面
- 面向开发者的本地 HTTP API 与 MCP 集成，请使用 GitHub 完整 release
- 不内置 API Key、帐号或托管模型服务；模型供应商和凭据完全由你控制

使用方法
1. 订阅后启动杀戮尖塔 2。
2. 按 F8，或点击游戏右侧的 AI 标签。
3. 在设置中添加 OpenAI 兼容接口和模型，然后使用对话或游玩。

兼容性
- 需要杀戮尖塔 2 v0.111.0 或更新版本。
- 本 Mod 只添加浮层和自动操作控制，不新增卡牌、遗物、平衡改动，也不修改存档数据。
- 本地双开联机目前使用游戏的 debug multiplayer-test 流程；Steam 可能阻止同机第二个游戏进程。
