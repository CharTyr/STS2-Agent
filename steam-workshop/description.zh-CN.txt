[h1]STS2 AI Agent[/h1]
给《杀戮尖塔 2》接上 AI：可以在游戏内直接配模型代打或双开组队，也可以把游戏接给 Claude Code、Cursor、Codex 等外部 Agent 通过 MCP 操控。

[b]本 Mod 不含免费额度或账号。[/b]游戏内自动游玩需自备 OpenAI 兼容 API Key（DeepSeek、OpenAI、硅基流动等）或本地 Ollama / LM Studio，可在设置里限死请求数和 Token 上限；只用外部 Agent 接管时无需在 Mod 内填 Key。不加新牌、不改游戏数值。

[h2]四种玩法[/h2]
[list]
[*][b]AI 代打 / 观战[/b]：自动处理选路、战斗、商店和事件。支持三档一键预设、整回合规划和出牌前高亮停顿，不满意按 [b]F7[/b] 随时拦截接管，也能切「战斗手动、其余自动」。
[*][b]本地 AI 队友[/b]：主菜单进「游玩 → 多人」一键拉起第二个游戏窗口，一人一角同局爬塔，支持联机续档、查看队友实时血量手牌、发消息或点快捷集火指令配合。房间仍留满 4 个位置，可再拉好友。
[*][b]外部 Agent 接入（MCP / API）[/b]：内置本机 Streamable HTTP MCP 与 REST/SSE API（仅监听 [b]127.0.0.1[/b]），无需装 Python。单人可在「设置 → MCP」开启并一键复制 Claude Code / Cursor / Codex 配置；联机可在「游玩 → 多人」切「外部 Agent」模式，自动为队友窗口开启 MCP，让外部客户端直接操控你的 AI 队友。推荐搭配仓库里的 [url=https://github.com/CharTyr/STS2-Agent/tree/main/skills/sts2-mcp-player]sts2-mcp-player[/url] skill；需要 stdio 或更多工具档位的开发者可从 GitHub 获取可选 Python MCP sidecar。
[*][b]局内参谋[/b]：直接问「拿哪张」「走哪条路」，AI 基于当前实况回答；也可以写几句跨局偏好让它按你的风格打。
[/list]

[h2]怎么用[/h2]
[olist]
[*]订阅后在 Steam 启动时选择 [b]Play with Mods / 带 Mod 启动[/b]。
[*]首次进游戏同意加载 Mod，在 Mods 菜单启用 [b]STS2 AI Agent[/b] 后重启游戏（若曾手动拷过旧版到游戏目录，请先删除，避免重复加载）。
[*]进游戏按 [b]F8[/b]（或点右侧 [b]AI[/b] 标签）：
  — [b]游戏内自玩[/b]：在「设置 → 快速配置」填好服务商、API Key 和模型名，点「测试主模型」通过，切到「游玩」页即可开始（拉 AI 队友请回主菜单）。
  — [b]外部 Agent 接管[/b]：单人直接去「设置 → MCP」打开开关复制配置；联机回主菜单在「游玩 → 多人」切「外部 Agent」模式拉起队友并复制队友 MCP 地址。
[/olist]
