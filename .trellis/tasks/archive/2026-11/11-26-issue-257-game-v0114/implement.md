# 实施与验证

1. 按 Steam 正式版和 public beta 确定支持矩阵。正式版 v0.111.1 是清单下限，测试目标为 public beta v0.114.0。
2. 把两版游戏的 API 差异集中在游戏兼容层。升级预览与健康检查共享签名解析结果，保留既有状态字段。使用行为测试覆盖旧签名、新签名、重载优先级及不可用分支。
3. 让 Windows 构建和预检显式传入已解析的程序集目录并打印版本和 SHA-256。使用两套实机程序集分别验证构建。
4. 让 GitHub 和 Workshop 打包入口将待分发的同一份 DLL 加载到两套禁用 Steam 的隔离实例，验证接口、MCP、升级预览和实际出牌。通过后写入两版实机报告。验证 GitHub ZIP 中 DLL 仍为报告中的哈希。
5. 运行 C# 核心测试、Python MCP 测试、静态闸门和发布门禁的失败路径。把当前证据和初次修复阶段证据分别写进验证记录。
