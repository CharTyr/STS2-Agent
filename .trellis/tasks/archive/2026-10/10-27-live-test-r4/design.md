# 测试设计

使用基于 origin/dev 的干净隔离工作树构建部署，以独立数字 clientId 和私有设置目录运行。离线检查和运行中检查均不指定 Python base URL。实机结果由界面、日志和本机 API 佐证；游戏流程由用户手动进入战斗，模型自动游玩。中断、密钥泄漏或存档异常时停止相关动作。

修复阶段：快速判断测试输出在 UI 层明确采用不换行、受容器宽度约束的控件，并允许读取完整错误；保持单次请求和现有错误分类。Python 问题从测试依赖注入入手，不改变生产发现行为。C# UI 与 Python 测试可以独立实现，主线程维护共享文档并汇总验证。熔断与热键只调查，避免为证据缺口改变行为。
